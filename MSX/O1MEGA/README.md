# O1MEGA for Omega MSX  
Space optimized PCB for additional 512KB Ram for the Omega MSX Computer.  
The PCB is based on the o8mega Board from MSXmakers.  
  
For [Schematics](KiCad/o1mega_THT_Schematics.pdf) see the KiCad folder.
